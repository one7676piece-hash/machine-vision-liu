📁專題報告

PCB Defect Detection & Accident Image Classification

專題一：PCB 瑕疵檢測

基於 YOLO 的 PCB 印刷電路板缺陷自動檢測系統

Automated PCB Defect Detection System Based on YOLO

YOLOv11 Python OpenCV Albumentations Data Augmentation

研究背景與目標

PCB 製造過程中不可避免地會產生各種缺陷，傳統人工目視檢查效率低且容易疲勞誤判。 本專題採用 YOLOv11 深度學習模型，建立一套能夠自動識別並分類 PCB 表面缺陷的 AOI 系統。

資料集

~2000 訓練影像數
6 缺陷類別數
80% 訓練集比例
20% 驗證集比例
缺陷類別： missing_hole、mouse_bite、open_circuit、short、spur、spurious_copper

資料增強策略

使用 albumentations 函式庫進行以下增強操作，以提升模型泛化能力：

  • 水平/垂直翻轉（Flip）
  • 隨機旋轉 ±15° (Rotate)
  • 亮度與對比度隨機調整（RandomBrightnessContrast）
  • 高斯雜訊添加（GaussNoise）
  • 隨機縮放與平移（ShiftScaleRotate）

開發流程

資料蒐集與整理

下載公開 PCB 缺陷資料集，統一標注格式為 YOLO 格式（.txt）

資料前處理與增強

撰寫 resplit_and_augment.py，解決中文路徑問題，執行影像增強

模型訓練

使用 YOLOv11 進行訓練（model_10），調整超參數優化結果

結果評估

以 mAP、Precision、Recall 等指標評估模型效能

系統整合與展示

建立推論介面，進行即時缺陷標注與分類展示

專題二：車禍影像分類

基於深度學習的車禍嚴重程度影像分類系統

Deep Learning Based Car Accident Severity Image Classification

CNN Transfer Learning Image Classification Multi-class

研究目標

透過分析車禍現場影像，自動判斷事故嚴重程度，輔助緊急救援資源的快速調度與優先級判斷。 本系統可應用於行車記錄器影像或監控攝影機的即時影像分析。

技術架構

骨幹網路 (Backbone) 採用預訓練 CNN 模型（如 ResNet、EfficientNet）作為特徵提取器
遷移學習 (Transfer Learning) 在預訓練權重基礎上 Fine-tune，加快收斂速度並減少所需訓練資料量
多類別分類輸出 依事故嚴重程度分類輸出，並附帶信心分數（Confidence Score）
