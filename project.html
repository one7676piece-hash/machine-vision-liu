PCB 板瑕疵邊緣偵測：短路與開路之自動化光學檢測

基於 MATLAB 的傳統機器視覺與邏輯容錯系統

Automated Optical Inspection for PCB Short and Open Defects

MATLAB 傳統影像處理 方向性相減 骨架交集驗證 AOI 線掃描系統

研究背景與目標

針對「幾何輪廓遭到破壞或改變」的 PCB 走線與銅箔缺陷進行檢測。PCB 走線具備規律且筆直的幾何輪廓，在工業相機拍攝下，高反射率的金屬銅箔走線呈現高亮度白色，與平坦的基板背景產生高對比邊緣。本系統旨在自動識別並分類兩種主要瑕疵：

🔴 短路 (Short / Solder Bridge)

兩條原本平行的走線邊緣之間，出現了不該存在的「橫向邊緣」將其連接，導致電路異常導通。

⭕ 開路 / 斷路 (Open / Mouse Bite)

連續的直線走線邊緣突然中斷，或是邊緣出現向內凹陷導致線路斷開，造成訊號無法傳遞。

軟體分析與核心檢測流程

1. 影像擷取與預處理

利用模板匹配 (Template Matching) 進行高精度座標對齊。將影像轉為單通道灰階並施加高斯低通濾波平滑化雜訊，隨後利用自適應二值化 (Binarization) 轉換為特徵明確的黑白遮罩。

2. 邊緣特徵強化與方向性相減

透過形態學膨脹 (Dilation) 建立邊緣容許誤差範圍（短路容許 3 像素偏移，斷路容許 2 像素偏移）。捨棄絕對值相減，利用邏輯運算元抓出凸出特徵：
• Test - Template 若殘留像素，判定為短路 (多出的邊緣)
• Template - Test 若殘留像素，判定為開路 (缺失的邊緣)

3. 骨架交集驗證 (Skeleton Validation)

濾除毛刺雜訊的最關鍵步驟。程式擷取「背景中心線 (skel_bg)」與「走線中心線 (skel_fg)」。真正的短路必跨越背景骨架，斷路必跨越走線骨架。透過交集點與形態學重建 (imreconstruct) 還原真實瑕疵，排除微小對位誤差。

4. 瑕疵聚類與視覺化輸出

對殘留像素進行連通域分析，計算面積大於安全容忍值即判定為真實瑕疵，並提取 Bounding Box 於原圖繪製紅色 (Short) 或藍色 (Open) 警示框。
