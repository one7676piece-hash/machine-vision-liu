Chapter 04

🎨影像處理技術

Image Processing Techniques

影像前處理

在進行特徵提取或缺陷檢測前，通常需要先對影像進行前處理，以提升後續演算法的效果：

灰階轉換 (Grayscale) 將彩色影像轉換為單通道灰階，降低計算量，簡化後續處理
直方圖等化 (Histogram Equalization) 增強影像對比度，使暗部細節更清晰，改善曝光不均問題
去雜訊 (Denoising) 去除感測器雜訊，提升影像清晰度，常用高斯濾波或中值濾波

空間域濾波

🔲 均值濾波

對鄰域像素取平均值，可平滑影像，但會使邊緣模糊

📊 高斯濾波

以高斯函數加權，平滑效果較自然，常用於去除高斯雜訊

📉 中值濾波

取鄰域中值，對椒鹽雜訊效果極佳，且能保留邊緣資訊

✏️ 銳化濾波

增強邊緣對比，使影像更清晰，常用 Laplacian 或 Unsharp Mask

邊緣偵測

邊緣是物件特徵的重要組成，常用的邊緣偵測演算法：

🔷
Sobel
計算水平與垂直梯度，對雜訊有一定抵抗能力
🔶
Canny
多階段處理，邊緣連續性好，為最常用的邊緣偵測演算法
🔷
Laplacian
二階導數，對邊緣敏感，但容易受雜訊影響
🔶
Prewitt
類似 Sobel，計算簡單，速度較快，適合即時應用

影像分割

將影像分割成感興趣的區域（ROI），是缺陷檢測的關鍵步驟：

全域二值化 (Global Thresholding) 以固定閾值將影像分為前景與背景，簡單但對光照變化敏感
Otsu 自動閾值法 自動計算最佳閾值，最大化類間變異數，廣泛應用於工業影像
自適應二值化 (Adaptive Thresholding) 根據局部區域計算閾值，對光照不均的影像效果更佳
語義分割 (Semantic Segmentation) 以深度學習逐像素分類，可精準識別複雜場景中的各類物件

Python 程式碼範例

使用 OpenCV 進行基本影像前處理：

import cv2 import numpy as np # 讀取影像 img = cv2.imread('pcb_image.jpg') # 灰階轉換 gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) # 高斯去雜訊 blur = cv2.GaussianBlur(gray, (5, 5), 0) # Canny 邊緣偵測 edges = cv2.Canny(blur, 50, 150) # Otsu 二值化 _, thresh = cv2.threshold(blur, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
